# devdash

[![Live Demo](https://img.shields.io/badge/🚀_Live_Demo-Visit-blue?style=for-the-badge)](https://mayank-dev-15.github.io/devdash-demo)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
![Language](https://img.shields.io/badge/Language-Python-green)

Terminal-based developer dashboard with system info, git stats, todos, and network monitoring.

`terminal` `dashboard` `system-info` `tui`

---

## ✨ Features

- System info dashboard (CPU, RAM, disk, network)
- Git repository statistics
- Todo management within the terminal
- Network monitoring
- Process viewer
- Interactive TUI (Text User Interface)
- Keyboard-driven navigation

## 📦 Installation

```bash
git clone https://github.com/mayank-dev-15/devdash.git
cd devdash
```

```bash
cd devdash
pip install -r requirements.txt
python main.py
```

---

## 💡 Usage

```bash
# Launch the dashboard
python main.py

# Controls:
# Arrow keys — navigate
# Enter — select
# Q — quit
# R — refresh
# T — todo panel
# G — git stats panel
```

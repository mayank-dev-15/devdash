## About

**devdash** is a terminal developer dashboard.

### Key Features

- System info dashboard
- Git repo stats
- Todo management
- Network monitoring
- Process viewer
- Interactive TUI

---

## Tech Stack

- Python
- curses
- psutil
- subprocess

---

## Controls & Usage

| Control | Action |
|---------|--------|
| `Arrow keys` | Navigate |
| `Enter` | Select |
| `Q` | Quit |
| `R` | Refresh |
| `T` | Todo panel |
| `G` | Git panel |
